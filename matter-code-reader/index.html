Matter Code Reader

Drop a photo of the QR label on a Matter device and get the 11-digit manual pairing code you can type into Home Assistant.

Manual pairing code

0000-000-0000

Everything runs in this page. Your photo is never uploaded — the QR is located and decoded in the browser, and nothing leaves your device.

In Home Assistant, go to Settings → Devices & Services → Add Integration → Matter and choose the option for entering a code by hand. The MT: payload usually works there too.
